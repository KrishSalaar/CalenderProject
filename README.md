# Classic Cool Calendar

A modern, interactive calendar application built with HTML, CSS, and JavaScript. This calendar provides a clean and intuitive interface for viewing dates and navigating through months.

## Features

- Clean and modern user interface
- Month navigation with previous and next buttons
- Current date display
- Responsive design
- Material Design icons integration
- Day of week labels
- Dynamic calendar days generation

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Google Material Icons

## Project Structure

```
├── index.html      # Main HTML file
├── style.css       # Stylesheet
└── script.js       # JavaScript functionality
```

## Getting Started

1. Clone this repository or download the files
2. Open `index.html` in your web browser
3. No additional setup required - the calendar is ready to use!

## Usage

- Use the chevron icons to navigate between months
- The current date is displayed at the top of the calendar
- The calendar automatically highlights the current day
- Days are organized in a standard Sunday-to-Saturday format

## Browser Support

This calendar works on all modern browsers including:
- Chrome
- Firefox
- Safari
- Edge
